# 企业中台资产管理与库存流转平台

## 项目简介
面向企业内部的资产与物资协同管理平台，涵盖采购入库、员工申领审批、库存流转及固定资产追踪，实现公司物资流转的全流程线上化审批和管控。

## 技术栈
- 基础框架：Spring Boot、MyBatis-Plus
- 认证与安全：JWT
- 中间件与缓存：Redis、Redisson、RabbitMQ
- 数据库与存储：MySQL、阿里云OSS

## 核心设计与技术亮点

### 1. Redis 分层缓存
- 部门层级结构树使用全局 Key 缓存。
- 用户权限菜单树结构按 userId 隔离缓存。
- 写操作后删除缓存不更新缓存，避免并发写覆盖脏数据。
- Redis 读写操作均使用 try-catch 降级兜底，Redis 宕机时自动回退到数据库查询，保证主流程可用。

### 2. 库存预占机制
- 库存表拆分为物理库存与预占库存两个字段。
- 员工提交申领时锁定预占量，审批驳回时释放预占，实际发放时扣减物理库存并同步释放预占。
- 配合 @Transactional 保证库存变动与流水写入的原子性，解决多人并发申领同一物资时的超发问题。

### 3. Redisson 分布式锁防超卖
- 采用 Redisson 实现细粒度分布式锁（仓库ID + 物资ID），控制并发申领。
- 通过 tryLock 设置等待时间与锁过期时间。
- 释放锁时校验当前线程持有状态并做安全移除，确保库存校验与预占扣减操作的原子性。

### 4. RabbitMQ 延时队列自动释放
- 基于 TTL 与死信交换机（DLX）实现延时队列。
- 超过指定时间未审批的申领单自动触发超时作废逻辑并回滚预占库存。
- 结合状态机与业务状态幂等校验，防止资源被长期锁死及重复处理。

### 5. 申领单状态机与流转审计
- 申领单状态规范流转：待审批 -> 待发放 -> 部分发放 -> 已完成。
- 支持按需部分发放，每次发放生成唯一出库流水。
- 保证每一笔物资出入库变动均可精准追溯至具体责任人和操作时间。

### 6. RBAC 权限与动态路由
- 基于标准的 6 张核心权限表（用户表、角色表、菜单表及其关联表）支撑多角色体系。
- 采用 JWT 实现无状态身份认证。
- 登录后根据当前用户角色动态查询授权菜单，在后端组装成树形结构返回，支撑前端动态路由渲染。
